## 🚀 Featured Projects

### 🕹️ Arcade — Web Game Collection & PWA
A free, installable browser arcade with 13 minigames built in plain HTML/CSS/JS (ES modules) — no build step, no external dependencies. Includes 5 classic games (Snake, 2048, Pong, Tic-Tac-Toe, Memory Match) and 8 original "Cyber Ops" games that teach defensive security concepts (phishing recognition, cipher basics, firewall rules, password strength, vulnerable code spotting, OSINT awareness, incident response, and patch prioritization).

**Tech:** HTML • CSS • JavaScript (ES Modules) • PWA • Service Worker • localStorage
**Features:** 13 playable games, offline support via service worker, installable PWA (Add to Home Screen), on-device progress/high-score persistence, accessibility-focused UI, cybersecurity-themed educational mini-games

[🔗 Live Demo](https://mohamedb999.github.io) | [📂 Repository](https://github.com/MOHAMEDB999/MOHAMEDB999.github.io)

### 🔍 MalwareLab — Malware Analysis & Threat Intel Framework
A Python framework exploring binary analysis, behavioral detection, and YARA rule generation, with VirusTotal/AlienVault OTX integration.

**Tech:** Python
[📂 Repository](https://github.com/MOHAMEDB999/MalwareLab)
